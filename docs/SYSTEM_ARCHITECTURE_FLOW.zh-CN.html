一项任务的运行流程

看一条主线即可：配置任务 → 启动运行 → 安排步骤 → 派发执行 → 查看结果

1
8091 配置中心

配置任务

定义角色、步骤和任务目标。

2
8080 工作流网关

启动运行

接收任务并保存运行状态。

3
主监督

安排步骤

判断现在该执行哪一步。

4
MCP 调度桥梁

派发步骤

把主监督的决定交给正确的执行机。

5
Codex 执行机

完成工作

独立完成当前步骤并返回结果。

6
8090 监控中心

查看结果

展示进度、步骤结果和最终总结。

↩ 执行结果送回主监督；如果还有步骤，就继续“安排 → 派发 → 执行”
MCP 的作用 检查：前一步是否完成 派发：选择执行机并启动步骤 回传：把执行结果送回系统
端口 8091 角色任务配置中心

管理角色、SOP 和任务，并发起运行。

端口 8080 Python 工作流网关

启动主监督并维护工作流运行状态。

内部调度组件 Codex Orchestrator MCP

检查依赖、派发步骤并回传执行结果。

端口 8090 任务运行监控中心

展示工作流进度、步骤结果和最终总结。
