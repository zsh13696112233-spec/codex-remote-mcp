# 独立定时任务管理升级

1. 按原部署流程备份配置中心 MySQL。停止所有旧版本 8091 实例，避免迁移期间旧调度器继续触发。
2. 部署新版配置中心并启动，Flyway 在现有 V25/V26 之后执行 V27：建立独立定时表，并停用任务定义里的全部旧定时配置。没有自动复制或启动规则；原任务定义、通知配置、运行历史及快照保留。
3. 在左侧“定时任务管理”重新创建：填写名称、选择 SOP、选择其下任务定义，设置每日北京时间或每隔 5–1440 分钟执行。启用后间隔模式等待完整间隔，例如每隔 40 分钟将在启用约 40 分钟后首次执行。
4. 确认下次执行时间，检查任务运行列表及任务定义配置的通知对象。停止期间错过的触发点不补跑。

只升级配置中心，不需要修改 Python 或监控中心协议。不得恢复旧调度实例与新实例同时运行；回退版本前先停用新规则并停止新实例，保留数据库和运行历史，不删除迁移记录。详细接口与行为以配置中心 README 为准。
