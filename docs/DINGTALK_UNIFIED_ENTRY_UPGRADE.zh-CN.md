# 钉钉统一入口与图片对话升级

先升级中央 Python 网关及本机 MCP，再升级远程 Sidecar，最后升级配置中心和监控中心。按既有流程备份 MySQL 和 SQLite；不清库、不修改历史迁移。配置中心新增 Flyway V20，移除通知对象的一对一限制，并为对话记录增加来源会话、图片引用和确认操作信息。

## 行为变化

- 启动命令为 `@机器人 完整任务定义名称`，不再使用空 @ 或“运行”定位固定群任务。名称应避免重复。启动不带图片。
- 所有能接触机器人的用户均可启动、查询和提出控制要求，任务或通知对象的启用设置不再充当人员权限。
- 后续使用完整工作流 ID 加问题；引用关联任务消息可省略 ID。无法解析引用时，改用编号，不依赖最近会话上下文。
- 对话在提问会话回复并 @ 提问人。引用优先使用实际消息标识；部分钉钉回复不返回消息标识时，只在当前会话最近 50 条已发消息中精确匹配引用正文，匹配不唯一或客户端不提供正文时要求带编号。
- 钉钉启动后在启动会话持续发送步骤进度、工具调用状态、可读思考摘要和最终结果，不额外发送给任务配置的通知对象。网页与定时运行继续按主动通知开关和配置对象推送；通知对象可被多个任务复用。
- 控制确认关联具体操作及提议人，网页不能代替钉钉提议人确认其操作；网页可正常提出并确认自己的操作。

## 图片部署要求

机器人需要调用钉钉机器人文件下载接口的权限。只支持实际发送给机器人的图片或富文本图片，不监听普通群消息中的全部图片。请把工作流编号、文字需求和图片一起发送，或引用关联图片消息补充需求。

每条消息最多 5 张 PNG、JPEG、WebP，合计最多 20 MB；输入图片与当前及历史产出共同遵守每个工作流 50 个文件的上限。输入原图保存在中央 SQLite 的独立表，不混入步骤产出。确认返工后原图关联目标步骤和后续步骤，原始运行快照不变。

需要收图的任务助手和步骤执行机必须配置绝对 `artifact_root`，并允许 `allow_write`。这是托管输入文件的写入许可，不改变 Codex 任务本身的只读/写入权限。只读任务仍按原沙箱执行。原图由 Python 经现有 app-server 连接写入目标执行机的 `artifact_root/conversation-inputs/<jobId>/`，随后通过 `turn/start` 的 `localImage` 输入交给 Codex。

目标 app-server 必须支持 `fs/createDirectory`、`fs/writeFile` 和图片输入。缺少能力、没有托管目录或传图失败时请求失败，不把中央机器路径当成远程路径，也不静默退化为纯文字。远程 Sidecar 使用已有机器身份与当前租约从中央读取所属工作流的步骤输入图；不需要开放新的公网端口。这不启用远程 `cumulative_files` 通用产出交接。

## 验证

普通消息版需先升级中央 Python、远程 Sidecar，再升级配置中心。新增 Flyway V21 保存启动会话回复地址，并为已有 Outbox 增加数据库生成的发送序号，避免同一时间入队的消息顺序不确定。步骤沿用现有事件上报；执行调用显式请求 `summary: auto`，升级远程 Sidecar 后同样生效，但是否产生可读摘要仍取决于模型。本版不需要新增卡片模板、权限或独立推送服务。

进度、工具开始/结束和最终结果按事件顺序发送；思考仅发送模型在完整事件中提供的可读摘要，没有摘要就不发送，不取原始推理文本。摘要不是逐字刷新。主监督的等待、查询进度工具消息过滤，业务步骤工具消息保留步骤名称。工具详情按内部使用要求不脱敏：展示原始文件路径、命令、参数及文本结果；完成时提供差异节选、退出码和耗时（事件提供时）。单字段最多 1500 字符，单次工具通知最多 4000 字符（不含截断提示），最多展示 10 个文件，超限明确提示。不转发结构化图片内容和钉钉图片传输字段。长消息按顺序拆分，每段携带工作流编号。过程消息不反复 @，最终回答、完成或需要处理时提醒对应用户。

任意会话的提问过程与最终回答只回复该次提问会话，不因此订阅整个任务。任务持续进度和最终结果使用应用 OpenAPI 向原启动群或人员发送普通文本，不依赖启动时临时回复地址的有效期。群聊完成或需处理时另发一条简短 @ 提醒，提醒仍使用会话回复接口；临时地址过期可能导致该提醒失败，但已发送的进度和结果正文不受影响。提问回复沿用该次消息的会话回复地址，失败后由用户重试，不新增补发、重连恢复或失败重试框架。历史运行没有启动回复地址时只发送正文。已有旧卡片与回调兼容保留，新运行和新过程消息均不创建或更新卡片。

大工具结果截断时保留类型、状态、关联提问与可读摘要，避免图片生成等调用缺少完成通知；钉钉标注原始详情已截断，不还原已丢失参数。工具详情以外的进度和摘要沿用原有脱敏：保留普通公开域名的 HTTP/HTTPS 交付链接，隐藏内部主机名、裸 IP 地址、带身份信息或凭据参数的 URL，以及本机路径和凭据文本。人员 OpenAPI 返回的查询键不作为真实钉钉消息编号保存，无法解析引用时仍使用工作流编号。

使用测试群分别验证名称启动、多人重复启动、跨群带编号提问、回复自动 @、引用消息与编号冲突、图文问答及确认后的按图返工。网页与定时运行各验证一次主动通知；钉钉启动验证过程消息回到启动会话，且配置的通知对象不额外收取消息。工具较多时普通消息也会较多，需真实钉钉验证发送频率与回复地址有效期。

文件下载失败、会话回复地址失效或 app-server 文件接口不可用时由用户重新发送。本次不新增重启恢复、断线补发或图片自动重传。现有任务运行及主动通知恢复逻辑沿用。输入文件保留供同一对话与已确认返工使用，不增加清理后台任务。
